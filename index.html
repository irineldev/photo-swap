🐶 Photo Swap Prank

Tap the bookmark on any upload page, and whatever photo gets picked uploads as the dog instead. Reload the page to undo.

💻 Computer

  1. Show the bookmarks bar (Ctrl/Cmd + Shift + B).
  2. Drag this button onto it: 🐶 Dog mode
  3. Open the upload site, click the bookmark, then pick a photo.

📱 Phone

  1. Copy the code below.
  2. Bookmark this page, then edit the bookmark: name it dogmode and replace its URL with the copied code.
  3. Open the upload site.
    Android Chrome: type dogmode in the address bar and tap the bookmark suggestion.
    iPhone Safari: open Bookmarks and tap dogmode.
  4. Pick or take a photo.

🧪 Test it here

Run the bookmark on this page, then pick any photo. The preview should show the dog.
